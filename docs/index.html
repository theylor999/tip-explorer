Tip Explorer

An interactive Shiny application for exploring restaurant tipping behavior.

Developing Data Products — Course Project

The data

The tips dataset (244 restaurant bills) records the total bill, tip, day, and smoker status.

`r mean(tips$tip)`

Embedded R code runs when the deck is built — mean tip is about $3.00.

The application

Three widgets drive the analysis:

  • Day of week — select box filters to one day
  • Minimum total bill — slider prunes small tickets
  • Smokers only — checkbox subset

The server logic

filtered <- reactive({
  df <- tips
  if (input$day != "All") df <- df[df$day == input$day, ]
  df <- df[df$total_bill >= input$total_bill, ]
  if (input$smoker_only) df <- df[df$smoker == "Yes", ]
  df
})

The histogram and summary table re-render on every widget change.
